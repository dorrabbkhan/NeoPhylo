# PHYLIP lab packs — data notes

Each `.json` file here is a schema-3 exercise with a `lab` block (v1.4
spec §6.2): handout, settings table, the "what PHYLIP's outfile showed
you vs what NeoPhylo shows you" note, and the PHYLIP chain it
reproduces. Expected numbers are checked against the committed PHYLIP
fixtures in `web/src/labs/packs.test.ts`; the menu options and defaults
in each settings table were read off the installed PHYLIP 3.697 menus.

## `dnadist-neighbor` dataset

- **File:** `fixtures/inputs/k80_10.fasta`, embedded verbatim in the
  pack's `data.fasta` (the test compares records byte for byte).
- **Shape:** 10 taxa (`t01`–`t10`) × 800 aligned sites, no gaps.
- **Provenance:** simulated in-house by this repository's fixture
  generators under K80 with κ = 6, so transitions dominate and the F84
  correction matters (`fixtures/README.md`, inputs section). Original
  data, no third-party source.
- **License:** the repository's license — AGPL-3.0-only (`LICENSE`); no
  entry in `THIRD_PARTY_NOTICES.md` is needed because nothing here is
  redistributed third-party material.
- **Expected numbers:** `fixtures/phylip/f84/k80_10.json` — dnadist's
  printed F84 matrix (`distances.F84`, 6 decimals) and `neighbor`'s NJ
  tree on that printed matrix (`nj.F84`, 5-decimal branch lengths),
  generated by `fixtures/generate_phylip.sh` with PHYLIP 3.697.
