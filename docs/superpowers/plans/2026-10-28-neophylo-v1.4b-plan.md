# NeoPhylo v1.4b (MEGA companion and data library) Implementation Plan

> **For agentic workers (Devin):** Run each task in its own session with `/neophylo-task v1.4b <N>` (Task 1 adds the `v1.4b` mapping). One task → one branch → one PR. Steps use checkbox (`- [ ]`) syntax. Read `AGENTS.md`, this plan's Global Constraints and Review Focus, and the spec sections each task names. Use `./scripts/check.sh quick` while iterating and the default check before pushing. Verify every write with `git diff`.

**Goal:** Make NeoPhylo a MEGA companion: MEGA's gap treatments and protein distances in the engine, `.meg` import and export, parity against a frozen MEGA-CC oracle, a bundled library of real datasets, and four MEGA handouts, with no change to existing results.

**Architecture:** Gap treatment is a `SiteFilter` in a new engine module (`site_filter.rs`) that turns an alignment into 0/1 column weights, fed into the existing `compute_weighted` path, so no distance function changes and `Pairwise` is today's path. Bootstrap gets a filtered entry point that maps resampled indices onto kept columns, so `Pairwise` replicates are bit-identical to today's. `.meg` I/O is a new `meg.rs` next to `phylip.rs`. The data library is static files under `web/public/library/` built offline by a script. MEGA handouts reuse the v1.4 lab framework with a `tool` field added to the `lab` block.

**Tech Stack:** As v1.4. Added: MEGA-CC (local only, never in CI or the repo) and MAFFT (build-time only, for the library script). Neither ships in the app.

**Spec:** `docs/superpowers/specs/2026-10-27-neophylo-v1.4b-mega-companion-design.md`. Earlier specs still apply where not overridden.

**Decided in this plan (spec §10 open items that need no oracle output):**
- **JSON identifiers:** `"Poisson"` (matches the existing `"Kimura"`, a named protein correction) and, only if Task 2 shows it is needed, `"JTT_MEGA"` (matches `"K2P_PHYLIP"`). Rust: `DistModel::Poisson`, `DistModel::JttMega`.
- **Site filter wire shape:** `{ "kind": "pairwise" | "complete" | "partial", "cutoff_pct": <integer 0–100> }`; `cutoff_pct` is present only for `partial`. Rust: `SiteFilter::{Pairwise, Complete, Partial { cutoff_pct: u8 }}`.
- **Partial coverage is integer arithmetic:** a column is kept when `present * 100 >= cutoff_pct * n` (no floats), unless Task 2's boundary fixture shows MEGA uses strict `>`; then the comparison flips and the fixture note says why.
- **Library datasets in links:** a library dataset is linked as `ds=<id>`, not embedded as `d=` data; an unknown `ds` id is a restore error with a message, like the existing `d=` failures.
- **The pair panel** is where removed columns are shown (NeoPhylo has no whole-alignment view; spec §6.2).

The remaining open items (MEGA-CC version and defaults, printed precision, JTT agreement, the filter-before-or-after-resampling source, accessions, MAFFT version) are answered by Tasks 2 and 8 and recorded in their notes files.

## Global Constraints

- **No existing number changes:** engine, parity, golden-hash, bootstrap and lesson-premise tests pass unmodified. Existing fixtures are not edited; new ones are added in their own PRs (CI fixture guard: a PR that modifies `fixtures/` cannot also change code).
- **`Pairwise` is today's path:** `compute(aln, m)` == `compute_filtered(aln, m, SiteFilter::Pairwise)` and `bootstrap_batch(...)` == `bootstrap_batch_filtered(..., SiteFilter::Pairwise, ...)`, bit for bit.
- **Old files and links:** `exercises/*.json` and `exercises/labs/*.json` (schema 2 and 3) load unchanged. `web/src/state/__fixtures__/v1-urls.json` and `v2-urls.json` restore identically.
- **MEGA-CC is never installed in CI, never committed, never fetched by a script that CI runs.** MEGA fixtures are regenerated only locally; CI reads the committed files. MEGA's own example data files are not committed.
- **The browser never fetches sequence data.** Library files are static under `web/public/library/`; the build script is the only thing that contacts NCBI or UniProt.
- **Size caps:** library datasets ≤ 30 taxa and ≤ 2,000 sites.
- **Science in Rust only:** filtering, coverage, the `.meg` grammar and all distances live in `crates/neophylo-core`. TypeScript draws and dispatches.
- **Determinism:** `libm` for all math; seeded `ChaCha8Rng`; no `Math.random`.
- **Engine never panics:** invalid cutoffs, empty filters, malformed `.meg` and matrix `.meg` files return `NeoError`.
- **New proptests go in new functions** (saved `cc` seeds of existing strategies must stay valid).
- **New schema keys are pinned for `null` and array values** (serde treats `null` as absent for `Option`).
- **Tokens only:** no literal colors or font sizes outside `web/src/design/tokens.ts`. Type scale 12–32 px.
- **Touch targets:** ≥ 40×40 px under `(pointer: coarse)`, measured with `hasTouch`, including plain links.
- **Owner-only:** MEGA-CC installation, fixture approval, snapshot baselines, dataset license sign-off, handout review sign-off, and the release tag.
- **Snapshots:** Chromium only, `maxDiffPixelRatio` 0.001, viewports 1920×1080, 1024×768, 768×1024, both themes. Baselines in `web/e2e/__screenshots__/`, owner-approved. Review evidence screenshots go in PR comments, never committed.

## Review Focus

1. **Filters that leave nothing, or leave a pair with nothing:** complete deletion on an alignment where every column has a gap → `NeoError` naming the filter and a readable sandbox message; a filter that keeps columns but leaves one pair with no comparable site → the existing `InsufficientOverlap` path, not NaN. → Tasks 3, 10.
2. **Partial cutoff at the boundary and out of range** (exactly 95% coverage; `cutoff_pct` 101, −1, 2.5, `null`, a string): the boundary follows MEGA's fixture; invalid values are refused with a field path in exercises and clamped-refused in the UI input. → Tasks 3, 6, 10.
3. **Hostile or odd `.meg` files:** CRLF line endings, a BOM, interleaved blocks with names in a different order, `.` identity in the first sequence, a `!Format` missing `DataType`, unterminated `"` comments, a distance-matrix `.meg`: each is parsed or refused with a line number, never a panic. → Task 5.
4. **Model menu × alphabet × filter switching in the sandbox:** switching from a protein dataset with `Poisson` to a DNA dataset, or from `K2P_PHYLIP` back to `K80`, never leaves an invalid model selected; κ is shown only for `K2P_PHYLIP`. → Task 10.
5. **"Open dataset" or "load this lab" over unsaved sandbox or editor work:** the user is asked first and declining keeps the work, as for v1.4 labs. → Tasks 11, 12.

Each line is pinned by a named test in the owning task.

### Task 3: Engine: `SiteFilter`, filtered distances and bootstrap

**Files:**
- Create: `crates/neophylo-core/src/site_filter.rs`

- Test: `crates/neophylo-core/tests/site_filter.rs` (new), `crates/neophylo-core/tests/site_filter_props.rs` (new, `proptest`)

**Interfaces:**
- Produces:
  - `pub enum SiteFilter { Pairwise, Complete, Partial { cutoff_pct: u8 } }` (serde `tag = "kind"`, `rename_all = "snake_case"`, ts-rs export). `Default` is `Pairwise`.
  - `pub struct SiteMask { pub weights: Vec<u32>, pub removed: Vec<usize> }` (ts-rs export).
  - `pub fn site_mask(aln: &Alignment, filter: SiteFilter) -> Result<SiteMask, NeoError>`. `cutoff_pct > 100` → `InvalidExercise { field: "site_filter.cutoff_pct" }`. No kept column → `NeoError::NoSitesKept { filter: String }` (new variant; `filter` is `"complete"` or `"partial 95%"`).
  - `pub fn compute_filtered(aln: &Alignment, model: DistModel, filter: SiteFilter) -> Result<DistanceMatrix, NeoError>` = `compute_weighted(aln, model, &site_mask(aln, filter)?.weights)`.
  - `pub fn bootstrap_batch_filtered(aln, model, method, filter: SiteFilter, seed, start, count) -> Result<BootstrapTally, NeoError>`; `bootstrap_batch` becomes a call with `SiteFilter::Pairwise`. Same pattern for `replicate_detail_filtered` / `replicate_detail`.
- "Missing" is the existing pairwise-deletion rule: DNA columns where `dist.rs`'s `is_base` is false; protein columns where `protein_index` is `None`. Reuse those functions; do not write a new character list.
- Resampling with a filter (if `mega-notes.md` says MEGA removes sites first): draw `resample_weights(seed, i, kept.len())` and add each weight to the kept column it indexes. Under `Pairwise`, `kept` is every column, so the draws, and therefore all existing replicate goldens, are unchanged. If the notes say MEGA filters after resampling, multiply the full-length weights by the mask instead; the `Pairwise` identity holds either way.
