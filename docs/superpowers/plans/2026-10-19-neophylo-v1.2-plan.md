# NeoPhylo v1.2 (Bootstrap, Consensus, Reference Rooting) Implementation Plan

> **For agentic workers (Devin):** Run each task in its **own session** with `/neophylo-task v1.2 <N>` (Task 1 adds the `v1.2` mapping). One task → one branch → one PR; done when all GitHub checks are green. Steps use checkbox (`- [ ]`) syntax. Read `AGENTS.md`, this plan's Global Constraints and Review Focus, and every spec section the task names first. Verify every write with `git diff` before committing.

**Goal:** Add nonparametric bootstrap, consensus trees and display rooting to NeoPhylo, completing the `seqboot` → `neighbor` → `consense` teaching lab with every step visible.

**Architecture:** The Rust engine owns all science: weighted distances, resampling with per-replicate ChaCha streams, groupings tallied as bitsets, support, consensus and rerooting. A single Web Worker runs the engine in batches, reporting progress and supporting cancel. The web app shows support on the original tree, with consensus tabs, a replicate view and a new lesson.

**Tech Stack:** As v1.1, plus a Web Worker (Vite worker bundling). Validation oracles: PHYLIP `consense`, R `ape::prop.clades`, `ape::boot.phylo`, `ape::rmtree`.

**Spec:** `docs/superpowers/specs/2026-10-19-neophylo-v1.2-bootstrap-design.md` (§ below). The v1 and v1.1 specs and plans still apply where not overridden.

## Global Constraints

- **No changes to existing results:** v1/v1.1 distances, simulation, golden hashes and lesson results are unchanged; every existing test passes unmodified.
- **Science lives in Rust only:** the worker and the UI never compute distances, splits, support or consensus.
- **Per-replicate RNG:** replicate *i* uses `ChaCha8Rng::seed_from_u64(seed)` then `set_stream(i as u64)`. The column index is `((rng.next_u64() as u128 * L as u128) >> 64) as usize`, L draws in order, nothing else consuming the stream.
- **Groupings:**
  - NJ: unrooted splits (both sides ≥ 2), canonical side = the one **not** containing taxon 0.
  - UPGMA: rooted clusters, the leaf set of each non-root internal node, size 2 … n−1.
  - Both are bitsets of 4 × u64 over alignment taxon order.
- **Failed replicates:** a replicate with any `Saturated` cell or any `InsufficientOverlap` pair is skipped and counted in `failed`. Support = count / `successful`. If all fail: `NeoError::BootstrapFailed { failed, total }`.
- **Consensus rules (§3.5):**
  - Strict: `count == successful`.
  - Majority: `count > successful / 2` (strict inequality).
  - Extended: majority, then remaining groupings by count descending, ties broken by ascending bitset value, adding each if compatible.
- **Support placement:** `BranchAttrs.support: Option<f64>`, a fraction 0–1, `serde(default)`. Displayed as `Math.round(100·s)`; weak means < 0.5 (thinner line plus a marker glyph, never color alone).
- **Rerooting:**
  - Outgroup = the reference root's child subtree with fewer leaves (tie: the child containing the alphabetically first label).
  - Root at the midpoint of the outgroup split's branch; the support goes on the ingroup-side edge only.
  - If the outgroup isn't a split: root at the midpoint of the terminal branch of the alphabetically first outgroup taxon, `outgroup_is_group: false`.
  - NJ only; display-only.
- **Limits:** replicates 10–1,000 (default 100); bootstrap seed default 1; 200 taxa max.
- **Worker:**
  - batches sized to about 100 ms
  - estimate after replicate 0; confirm required if `totalMs > 10,000`
  - cancel acknowledged within 1 s, or terminate and respawn
  - results from a stale `jobId` are ignored
- **URL v3:** adds `bootstrap: { replicates, seed, view, ran }`. Links never contain results. Auto-run on open only if the estimate is ≤ 10,000 ms.
- **Fixtures:** `fixtures/` changes only in Task 2 (owner gate). Tolerances are never loosened without an owner sign-off line.
- **Performance:**
  - lesson-sized data (≤ 10 taxa, ≤ 1,000 sites): 1,000 replicates < 1 s (Chromium, CI)
  - the large-case ETA within 30%; no main-thread task > 50 ms during a run
- **Lesson rules:** v1 conventions plus the v1.1 checkpoint fixes (no spoilers, results only at the end).

## Review Focus

1. **Trees with no groupings to test** (3 taxa: none; 4 taxa: one): the bootstrap panel explains "With N taxa, an unrooted tree has K grouping(s) to test" instead of an empty result or an error. → Tasks 4, 11.
2. **Navigating during a run** (stepping back, switching Concept/Math or consensus tabs, opening the pair panel) neither cancels nor corrupts the run. Changing the data, model or method cancels it and clears the results. → Task 10.
3. **Changing replicates or seed after a run:** results stay visible but are labeled "Results for 100 replicates, seed 1; settings changed, run again to update." They're never presented as matching the new settings. → Task 11.
4. **Newick export with support labels and quoted taxon names** (`'Homo sapiens'`, `O'Brien`) round-trips through NeoPhylo's parser and R's `read.tree`, with support values intact. → Task 15.
5. **Support on the rerooted cytochrome c tree:** after a bootstrap run on `cytochrome-c`, the label on the drawn (horse, human) branch equals that split's support from the tally, and the rerooted root edge shows its support once. → Task 11.
