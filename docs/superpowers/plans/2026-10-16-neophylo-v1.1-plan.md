# NeoPhylo v1.1 (Protein + PHYLIP I/O) Implementation Plan

> **For agentic workers (Devin):** Run each task in its **own session** with `/neophylo-task v1.1 <N>` (Task 1 teaches the skill to select this plan). One task → one branch → one PR; done when all GitHub checks are green. Steps use checkbox (`- [ ]`) syntax. Read `AGENTS.md`, this plan's Global Constraints and Review Focus, and every spec section the task names before starting.

**Goal:** Let NeoPhylo replace the `protdist` → `neighbor` protein teaching workflow: protein alphabet, PHYLIP-format I/O, p/Kimura/JTT distances, JTT simulation, a likelihood pair panel, and two protein lessons.

**Architecture:** Hybrid (spec §1). Alignments carry an `Alphabet`; a new `model` module holds eigen-decomposed substitution models (JTT first) used by JTT distances and JTT simulation. DNA distance and DNA simulation code paths stay byte-for-byte unchanged, guarded by the existing golden hashes.

**Tech Stack:** As v1, plus: Python 3 + numpy (offline constants generator only, not a runtime dependency); PHYLIP `protdist` and `neighbor` and R `phangorn::dist.ml` in fixture generation.

**Spec:** `docs/superpowers/specs/2026-10-16-neophylo-v1.1-protein-design.md` (§ numbers below). The v1 spec and plan still apply where not overridden.

## Global Constraints

- **DNA unchanged:**
  - No change to DNA parsing behavior, the DNA distance formulas, or the DNA simulation code path.
  - The three v1 golden hashes in `fixtures/sim_golden.json` must not change.
  - Every v1 lesson and v1 URL state must give an identical step-0 matrix.
- **Protein state order:** `ARNDCQEGHILKMFPSTWYV` = indices 0–19, everywhere (constants, counts, sampling).
- **Protein missing characters:** `B Z J X U O * - ?` are pairwise-deleted for every model. Input is case-insensitive.
- **Detection rule (verbatim, spec §3.1), ignoring `-`/`?`:**
  - Protein if any character is in `E F I L P Q J O Z X *`.
  - Otherwise DNA if ≥ 90% are in `A C G T U N`.
  - Otherwise protein.
- **JTT fit:**
  - Brent's method on d ∈ [0, 10], absolute tolerance 1e-10.
  - `Saturated` if d̂ is within 1e-6 of 10; d̂ = 0 exactly for identical comparable sites.
  - P(t) entries clamped to ≥ 1e-300 before taking the log.
- **Kimura:** `x = 1 − p − 0.2p²`; `Saturated` if `x ≤ 0`; else `d = −ln x`.
- **Units:** Q normalized so `−Σ πᵢ qᵢᵢ = 1` (expected substitutions per site).
- **Math functions:** `libm` only for exp/log in core (the clippy rule already enforces this).
- **JTT constants are generated** by `scripts/gen_models.py` from `data/models/jtt.dat`; never hand-edited. The generated file is checksum-guarded.
- **Fixtures:** `fixtures/` changes only in Task 2 (owner gate) and a new golden in Task 7. Tolerances are never loosened without an owner sign-off line in `docs/decisions.md`.
- **Performance budget:** full JTT matrix for 200 taxa × 1,000 sites in under 2 s in the browser (single-threaded wasm).
- **Display precision:** 3 decimals in the UI (v1 rule). The PHYLIP matrix export uses 6 decimals.
- **Lesson rules:** v1 lesson conventions apply (at_step = join number, no placeholder text, no predict on NJ's final join).
- **New error variant:** `ModelAlphabetMismatch { model: String, alphabet: Alphabet }`. All other failures reuse v1 variants.

## Review Focus

1. **Messy PHYLIP files from old handouts:**
   - tabs between name and sequence
   - strict names that run straight into the sequence (exactly 10 characters, no space)
   - trailing spaces at line ends
   - blank lines between interleaved blocks

   All of these must parse. → Task 4.
2. **Raw, unaligned UniProt sequences pasted** (differing lengths): `UnequalLengths` with a body saying the sequences must be aligned first (naming Clustal Omega/MAFFT as examples), not just the lengths. → Task 10.
3. **Overriding the alphabet while an incompatible model is selected** (e.g. JTT, then "Treat as DNA"): the correction switches to the alphabet's default (DNA: JC69, protein: JTT) with a one-line notice. Never a stuck error state. → Task 10.
4. **Translated proteins with a trailing `*` on every sequence, in lowercase:** parse as protein, with `*` treated as missing. → Task 3.
5. **Pair panel on an identical pair, and on a pair with zero comparable sites:** an identical pair shows d̂ = 0 with a sensible curve on [0, 0.5]; a zero-overlap pair shows the "no comparable sites" message inside the panel instead of crashing it. → Task 11.
