**Goal:** Build NeoPhylo v1, a browser-based teaching tool where students step through NJ and UPGMA on simulated or imported DNA data and compare the result with a known true tree.

**Architecture:** A pure-Rust engine (`neophylo-core`) does all the science and emits per-step traces. A logic-free `wasm-bindgen` layer (`neophylo-wasm`) exposes it, with TypeScript types generated by `ts-rs`. A React 19 + Vite static site renders everything as SVG, and its state lives in the URL.

**Tech Stack:**
- Rust (stable): serde, serde_json, serde-wasm-bindgen, wasm-bindgen, ts-rs, rand_core, rand_chacha, libm, proptest, cargo-fuzz.
- Web: React 19, TypeScript (strict), Vite, KaTeX, lz-string, vite-plugin-pwa, Vitest, Playwright, @axe-core/playwright, ajv.
- Reference tools: R (ape, phangorn, jsonlite) and PHYLIP 3.697.

**Spec:** `docs/superpowers/specs/2026-10-15-neophylo-design.md`. Section numbers like §4.5 refer to it.

## Global Constraints

- Engine floats are `f64`. In `neophylo-core`, `exp`, `ln`, `powf` and `sqrt` come from `libm`; `f64::exp`, `f64::ln` and `f64::powf` are banned via clippy `disallowed-methods`.
- No unseeded randomness anywhere. Use `ChaCha8Rng::seed_from_u64(seed)` only; `Math.random` is never used in `web/src` (a lint rule enforces this).
- The wasm build is single-threaded: no rayon, no `SharedArrayBuffer`, no atomics target features.
- Limits:
  - At most 200 taxa (`TooManyTaxa { max: 200 }`) and at least 3 taxa (`TooFewTaxa { min: 3 }`) to build a tree.
  - At most 100,000 sites for import.
  - Simulation length: the engine accepts 10–100,000; the UI and exercise files allow 10–10,000.
  - Traces are produced only when requested; the UI requests them only when the number of taxa is 50 or fewer.
- Tie-break: the lowest `(i, j)` in lexicographic order with `i < j`, over active-cluster indices. Original taxa come first in input order, and new nodes are appended in creation order.
- Node IDs: leaves are `NodeId(0..n)` in input order, and internal nodes are numbered in creation order. NJ's root is the central node from the final three-way join; UPGMA's root is the last merge.
- The engine never panics on any input. Every failure is a `NeoError` variant.
- `neophylo-wasm` contains no logic, and no engine math is ever reimplemented in TypeScript.
- Generated TypeScript lives in `web/src/engine/generated/` and is never hand-edited.
- Wasm bundle under 1 MB gzipped.
- Browsers: the last two versions of Chrome, Edge, Firefox and Safari.
- Files are single-purpose and under about 400 lines.
- `fixtures/` changes only through its generator scripts, and never in the same PR as engine code.

**Resolved spec gaps (to be merged into the spec in Task 1's PR):**
1. Added `NeoError::TooFewTaxa { min, got }`.
2. `build_tree` takes `BuildOptions { trace: bool }` and returns `trace: Option<Trace>`, because a 200-taxon trace would be over 100 MB.
3. Added a wasm function `load_exercise(json)` that returns `Result<Exercise>`.
4. Duplicate taxon names are reported as `NeoError::Parse` at the duplicate's line.

## Review Focus

Inputs and conditions the spec implies but no headline test covers, most likely to cause trouble first. Each has a pinned test in the owning task.

1. **Messy pasted FASTA:** CRLF line endings, a UTF-8 BOM, wrapped sequence lines, blank lines, trailing whitespace, and duplicate names. Students paste from Word and email. Expected: everything parses except duplicates, which give `Parse` at the right line. → Task 3.
2. **Taxon labels with spaces, quotes, Unicode or markup** (`Homo sapiens`, `O'Brien`, `<b>`) must round-trip through Newick, render as text (never as markup) in the SVG view and the exported SVG, and be escaped in the R script. → Tasks 4, 15, 24.
3. **All-identical sequences** (a zero matrix, so every pair ties) give a deterministic tree with zero-length branches and no NaN anywhere in the trace. → Task 6.
4. **Fewer than 3 taxa** (e.g. a paste with 2 sequences) give `TooFewTaxa`, shown as a friendly message rather than a blank screen. → Tasks 6, 20.
5. **An exercise true tree missing a branch length** gives `InvalidExercise { field: "true_tree" }` before any simulation runs. → Task 9.

### Task 6: Neighbor-Joining with trace

**Files:**
- Create: `src/algos/mod.rs`, `src/algos/nj.rs`, `tests/nj.rs`

- [ ] **Step 1: Write failing tests:**
