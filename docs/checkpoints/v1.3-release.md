# v1.3 release checkpoint — design system, bundled fonts, responsive layout

Owner-run manual checklist before tagging `v1.3.0`, modeled on the v1.2
release checkpoint (v1.2 plan Task 16 step 5). Everything automated is
already green — `E2E=1 RPARITY=1 FUZZ=1 ./scripts/check.sh` — so this is
the pass a machine can't do: every lesson at every width in both themes,
a real tablet, a projector, a printer, a locked-down browser, and links
that were shared before this release existed.

Use the deploy preview of the release-candidate commit, not a dev
server. Record findings inline under each item; anything blocking goes
back as a `fix/` branch before the tag. Spec references are to
`docs/superpowers/specs/2026-10-21-neophylo-v1.3-design-system-design.md`.

## 1. Every lesson, both themes, all four widths

Play each lesson start to finish in **light and dark** at **768, 1,024,
1,280 and 1,920 px** wide (§2, §6.1):

- [ ] `nj-basics` — prompts gate, joins reveal, RF shown at the end.
- [ ] `upgma-fails` — the clock-breaks-UPGMA point lands.
- [ ] `saturation` — the fix buttons make progress; the "Still
      saturated at length {n}: {k} pair(s) remain…" feedback reads
      correctly (§6.9).
- [ ] `protein-models` — the pair panel and the JTT likelihood curve.
- [ ] `cytochrome-c` — real data, reference comparison, reroot toggle.
- [ ] `bootstrap-basics` — the `predict_branch` prompt gates Run; the
      note sequence plays to the closing note.

At each width and in each theme:

- [ ] The header stays on **one row**; when a lesson title is too long
      it truncates with "…" and hovering shows the full title (the
      header-title fix, `docs/decisions.md` "v1.3 fixes").
- [ ] No sideways page scrolling; every leaf is visible without
      scrolling the tree panels (§8.2).
- [ ] The stepper is pinned to the bottom and fully visible (§6.2).
- [ ] At ≥ 1,280 the controls column is on the left; at 1,024–1,279 the
      controls live in the Settings drawer and the explanation moves
      below the center; at 768–1,023 it's one column — true tree,
      inferred tree, matrix, prompts, explanation (§6.1).
- [ ] Below 1,024 the pair panel, replicate panel and PHYLIP help open
      as full-screen sheets; Esc closes and returns focus (§6.2).
- [ ] Every header control — including "Dark mode" — is on screen and
      clickable with no horizontal page scroll.
- [ ] No console errors, no clipped or overlapping labels, all text
      ≥ 12 px.

## 2. A real tablet, or a half-width window

The §8.4 owner gate: a real tablet, or a desktop window dragged to half
the screen.

- [ ] At 768×1024 the single-column layout holds; dragging the window
      wider/narrower reflows live.
- [ ] Mid-lesson, rotate 768×1024 → 1024×768: the step number and the
      predict selection are kept (Review Focus 5).
- [ ] With the Settings drawer open, rotate: the drawer stays open and
      focused, or closes with focus back on its button (§6.4).
- [ ] On a touchscreen, buttons, matrix cells and `predict_branch`
      targets are all ≥ 40×40 px and tappable (§6.5).
- [ ] **Tour on Firefox at tablet width:** on a first visit at
      768×1024 in Firefox, step through all four tour steps with real
      clicks — every "Next" lands, the highlight ring tracks its target,
      and the tour doesn't show again on reload (the Firefox
      scroll-race fix, `docs/decisions.md` "v1.3 fixes"; §6.7).

## 3. Presenter mode on a large screen

The §8.4 owner gate, on a projector or a large monitor at the back of
the room.

- [ ] Toggling "Presenter mode" scales type and spacing ×1.5
      (`data-presenter`), hides the controls column and the drawer
      button, and enlarges the step buttons (§6.6).
- [ ] Every label is readable from the back row; nothing is clipped.
- [ ] Toggling it mid-bootstrap keeps the run going; toggling it with
      the replicate panel open keeps the panel open and re-styled
      (Review Focus 4).
- [ ] It persists across a reload on the same machine and never appears
      in a shared link (§7.4).

## 4. Printing an exported figure

The §8.4 owner gate: a printed exported figure (§7.3, §4.3).

- [ ] In **dark** mode, export the cytochrome-c tree as SVG: the file
      uses the light print palette anyway (the default, whatever theme
      is on screen). Check "Match screen theme" and export again: that
      file uses the dark palette.
- [ ] Print both the exported SVG and the exported PNG: labels are
      crisp, support pills legible, nothing clipped.
- [ ] Open the exported SVG on a machine **without Inter installed**:
      the tree looks identical — the needed font subsets are embedded
      as base64 `@font-face` data (§4.3).
- [ ] Export a tree with a name outside the bundled subsets (e.g.
      `中文名`, `🦋 Morpho`): the export warns exactly "Some names use
      characters outside the bundled fonts and may look different in
      other programs." (Review Focus 1).

## 5. Blocked storage

Private window, or devtools → storage disabled (Review Focus 3, §7.4).

- [ ] The app loads in the light theme with **no console errors**.
- [ ] The theme toggle works for the session (it just can't persist).
- [ ] The tour shows on first load and **not again** within the same
      page session.
- [ ] A full lesson and a bootstrap run complete normally.

## 6. Browser zoom at 200%

Review Focus 2.

- [ ] In a 1,280 px window at 200% zoom (≈ 640 CSS px): the compact
      layout applies, the page never scrolls sideways, the stepper
      stays visible and every leaf is reachable.

## 7. Old links

Spec §8.1: the v1.1 and v1.2 link corpora restore identically.

- [ ] Take real shared links from production (made before this
      release): open each on the staging deploy — same lesson, same
      step, same matrix, same analysis settings.
- [ ] A link with `#x=` state does **not** trigger the tour (§6.7).

## 8. Offline and lazy formulas

§7.2, §4.2.

- [ ] Load the site once online, then go offline and reload: a lesson
      loads, a bootstrap run completes, and bundled-font text renders
      the same (fonts, the worker chunk and the KaTeX chunk are
      precached).
- [ ] Online, on a lesson's Concept/Math toggle: switching to Math
      shows "Loading formulas…" briefly, then renders. Offline after a
      first visit, the same toggle still renders formulas.
- [ ] A formula too wide for its box scrolls **inside** the box — with
      the fade at the clipped edge — and the page never scrolls
      sideways (the math-line fix, `docs/decisions.md` "v1.3 fixes").

## 9. Tag the release

- [ ] All of the above signed off; CI green on `main`.
- [ ] `git tag v1.3.0` on the release commit; push the tag (production
      deploys on tags). The owner tags; the agent never does.
- [ ] Fill `date-released` in `CITATION.cff` (left for the owner in the
      Task 16 PR).
