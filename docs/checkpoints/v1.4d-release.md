# v1.4d release checkpoint — tree reading

Owner-run manual checklist before tagging `v1.4.3`, modeled on the v1.4c
release checkpoint (`docs/checkpoints/v1.4c-release.md`). Everything
automated is already green on the candidate — `./scripts/check.sh` plus
the full e2e browser matrix in CI — so this is the pass a machine can't
do alone: every lesson and form on every way a student can work through
it, every drawing style in both themes, a set built in the editor and
shared, every reading sheet and key on paper, the coverage manifest read
against the instruments it mirrors, and every carried v1.4c item
re-proven on the new deploy.

(Tag name: `v1.4d` is the milestone name, not a valid release tag —
production deploys only on `v*.*.*` tags (`.github/workflows/ci.yml`).
`v1.4.3` is the proposed release tag; the owner confirms the name.
v1.4c shipped as `v1.4.2`. The agent never tags.)

How to run it: `docs/release-checkpoint.md`. `scripts/checkpoint/run.sh`
automates most items below against the deploy preview (its "Automation
map" says which), so the remaining manual pass is short:

    scripts/checkpoint/run.sh --pr <PR> --tag v1.4.3 --milestone v1.4d \
        --checklist docs/checkpoints/v1.4d-release.md

Use the deploy preview of the release-candidate commit, not a dev
server. Record findings inline under each item; anything blocking goes
back as a `fix/` branch before the tag. Spec references are to
`docs/superpowers/specs/2026-11-18-neophylo-v1.4d-tree-reading-design.md`.

Every number below comes from committed content or committed test
output — the reading sets in `exercises/reading/` and
`exercises/reading/coverage/` (ids, titles, modes and item counts are
read from the files, never typed from memory), the coverage manifest
(`exercises/reading/coverage/manifest.json`), the link corpora in
`web/src/state/__fixtures__/` — never typed from memory. Section numbers
(§) match the test names in `scripts/checkpoint/browser/release.spec.ts`,
which reports each item it proves. **Carried v1.4c items keep their
§1–§15 numbers** — the same tests run them — and the v1.4d reading
checks are §16–§20; §21 is the triage list.
