# NeoPhylo icon — v1.3 owner gate outcome

The owner chose **Option C — "Node link"** on PR #71. The canonical mark
is `web/public/brand/icon.svg`, a byte-for-byte copy of
`web/public/brand/options/option-c.svg`; the unchosen Option A and
Option B files were deleted in the same PR.

**Color:** the file draws in `currentColor` with `color="#aa3bff"` on the
root — the light-theme `accent` token, used as the canonical brand color
(brand assets like favicon/PWA/og-image are theme-independent). An inlined
copy can still be recolored with CSS `color` if a context wants the dark
accent instead.
